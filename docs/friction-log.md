# Friction Log

One entry per Friction met while building the prototype on QUL, in the order met. Severity: low (annoyance), medium (cost real time), high (blocked or nearly gave up). Objective numbers refer to the five role objectives.

| # | Step | Expected | What happened | Severity | Time lost | Objective |
|---|------|----------|---------------|----------|-----------|-----------|
| 1 | Download any Resource | Click "Download json" and get a file | Signed out, every download link 302s to the sign-in page. An account is mandatory before a Builder can see a single byte of data. Nothing on the resource page says so. | medium | 5 min | 1 |
| 2 | Pick the Indopak script | One obvious Indopak ayah-by-ayah Resource | Three ayah-by-ayah Indopak variants (Indopak, Indopak Nastaleeq, Digital Khatt Indopak) with no description of how they differ or which font each needs. Chose the one whose page lists a related font. | medium | 10 min | 1 |
| 3 | Check the script's license | A license line on the resource page | No license, copyright, or permission statement anywhere on the page. Same for every Resource in this run. The FAQ says to check "dataset-specific licensing details" that do not exist. | high | 15 min | 2 |
| 4 | Read the script JSON | Plain Unicode text | Every ayah ends with a private-use-area character that renders as a box in any font except the matched QUL font. Not mentioned on the page. | low | 5 min | 1 |
| 5 | Get the Indopak font | Copy the @font-face from the docs | The example @font-face has an empty font-family, and the CDN path in it says "Hanafi" where "Hafs" is meant (the tag on the page says Hafs). The path works, but it looks wrong. | low | 5 min | 1 |
| 6 | Pick a transliteration | A Resource named for its source | Seven English-ish variants named "Transliteration", "English Transliteration(Tajweed)", "(RTF Updated)", "Syllables 1/2/(Old)". No author, no source, no sample beyond one ayah. Picked by reading previews. | medium | 10 min | 1 |
| 7 | Pick a translation download | One json file | Saheeh International offers eight download variants (simple, chunks, inline footnotes, footnote tags, each in json and sqlite) with no explanation of the differences. Guessed "simple". | low | 5 min | 1 |
| 8 | Read the tafsir JSON | One object per ayah | Values are mixed types: grouped ayahs are objects with an ayah_keys list, and the ayahs they cover are bare strings pointing at the group key ("2:4": "2:3"). A naive `entry.text` read crashes on 20 ayahs. Ten entries also contain HTML. | medium | 15 min | 1 |
| 9 | Find the recitation Resource | One Alafasy entry | Four Alafasy entries (411 surah-by-surah, 118 ayah-by-ayah, 414 "Streaming", 327 with English). "Streaming" is never explained. | low | 5 min | 1 |
| 10 | Read the segments JSON | Ayah start and end times | Segments are word-level triples [wordPosition, startMs, endMs] with ayah bounds in timestamp_from/to. Units are only inferable from the values. Thirty ayahs start before the previous ayah ends, and the audio for surahs 2 to 114 has no bismillah, which an ayah-highlighting player has to know. | medium | 15 min | 1 |
| 11 | Find the reciter's name in the data | A reciter field in surah.json | surah.json has only surah_number, audio_url, duration. The reciter's name lives only on the catalog page and has to be hard-coded. | low | 2 min | 1 |
| 12 | Follow the docs nav | "Downloading & Using Data" opens | The nav link goes to /docs/downloading-and-using-data, which is a 404 quiz page. The real page is /docs/downloading-data. | low | 3 min | 1 |
| 13 | Check bundle size | Small text bundle | 7.7 MB for all text Resources plus font; the tafsir is 1.8 MB and segments 2.1 MB. Acceptable for a server-read bundle, too large to ship to a browser wholesale. | low | 0 | 1 |
